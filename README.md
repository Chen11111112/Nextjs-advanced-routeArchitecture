# Next.js Full-Stack Practice Project 🚀

你好！歡迎來到本教學專案！本專案旨在透過循序漸進的實作，帶領開發者掌握現代 Next.js 全端開發的核心技術。

* **聚焦全端實現**：本專案**不會**花時間講解過於基礎的 React 語法（如 `useState`、`useEffect` 基本操作等）。
* **核心技術棧**：全力聚焦於 **Next.js App Router** 架構以及 **Server Actions** 等全端資料流與互動實現。
* 專案中的每一個單元皆以獨立的資料夾命名（例如 `day-01`、`day-02` ...）**存放於app資料夾中**。

> 我刻意採用 **Day** 而非 Chapter 來命名每一個學習單元。希望大家在學習時能維持 **「一天專心學一種技術」** 的節奏，不要貪快，扎扎實實地把每個觀念與實作消化吸收。
---

## 📁 學習方式
1. 專案中的每一個單元皆以獨立的資料夾命名（例如 `day-01`、`day-02` ...）存放於app資料夾中。
2. 請進入對應的 `day-x` 資料夾，每個資料夾內皆備有專屬的 `README.md`，詳細說明該單元的：
   * 學習目標與核心觀念
   * 實作步驟與程式碼重點
   * 練習作業或挑戰

---

## 🛠️ 技術核心 (Tech Stack)
* **Framework**: [Next.js (App Router)](https://nextjs.org/)
* **Styling**: SCSS / CSS Modules
* **Server-side**: Server Actions, Server Components (RSC)
* **Language**: TypeScript
